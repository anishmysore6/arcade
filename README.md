# ARCADE LAB

**ENGR-126 Project 20a**: four classic arcade games in one Python program, built with Pygame.

ARCADE LAB is a retro arcade cabinet in a single file. A neon main menu leads to four games, and they all share the same look, sounds, pause system and high-score saving. Every graphic and sound effect is generated by the code, so there are no image or audio files.

The same file runs on a Windows laptop (PyCharm) and in a web browser (built with pygbag and published on Netlify).

---

## The four games

### 1. Viper Bite (Snake)
- Steer a snake around the grid, eat apples, and avoid the walls and your own body.
- Starts 4 segments long and speeds up as it grows, up to a top speed.
- Apples come in different colors, and each one sends a wave of its color down the snake's body from head to tail.
- **Golden apples** sometimes appear and are worth 5 points instead of 1.
- Smooth movement between grid squares, with particle bursts when you eat and when you crash.

### 2. Brick Fall (Tetris-style)
- A 10 x 20 board with all seven shapes: I, O, T, S, Z, J, L.
- A **7-bag randomizer** (every group of 7 pieces contains each shape once), a next-piece preview, and a short lock delay before a piece locks.
- Smooth key repeat when you hold a movement key. Clearing several rows at once scores more.
- Score, rows cleared, level and personal best are shown. The pieces fall faster as your level goes up.

### 3. Chomp Maze (Pac-Man-style)
- Eat every dot to clear the maze. Power pellets turn the ghosts blue so you can eat them for bonus points.
- Eaten ghosts race back home, then rejoin the chase. Tunnels wrap you to the other side of the maze.
- 3 lives. You move faster on each new level, and turns are forgiving if you press a little early or late.
- **Four ghosts, each with its own personality:**

| Ghost | Color | Behavior |
|---|---|---|
| Blaze | Red | Chases your current position directly |
| Petal | Pink | Aims 4 tiles ahead of you to cut you off |
| Frost | Cyan | Flanks you, working with Blaze to trap you |
| Sunny | Orange | Chases from a distance, then retreats to its corner when it gets too close |

- The ghosts switch between scatter and chase modes and use pathfinding. Blue ghosts are slower, and eaten ghosts move fast on their way home.

### 4. Paddle Duel (Pong-style)
- First to **11 points** wins. Where the ball hits the paddle changes its bounce angle, and the ball speeds up after every hit. There is a short pause before each serve.
- **Modes:** Computer Easy, Computer Normal, Computer Hard, or Two Players.
- The computer predicts where the ball will arrive. Easy reacts slowly and makes more mistakes, Hard reacts faster and makes fewer, and none of them is unbeatable.
- The ball leaves a trail, and particles fly on hits and goals. Your total wins and losses against the computer are saved, and you can switch opponents after a match.

## Controls

### Main menu
| Key | Action |
|---|---|
| Arrow keys or WASD | Move between game cards |
| 1 - 4 | Jump straight to a game |
| Mouse click | Select a card |
| Enter or Space | Launch the selected game |
| Esc | Quit (desktop only) |

### In every game
| Key | Action |
|---|---|
| P | Pause (P, Enter or Space to resume) |
| Esc | Back to the main menu (new high scores are kept) |
| M | Sound on / off, from anywhere |

### Game controls
| Game | Controls |
|---|---|
| Viper Bite | Arrow keys or WASD |
| Brick Fall | Left/Right move, Up or X rotate clockwise, Z rotate counter-clockwise, Down soft drop, Space hard drop |
| Chomp Maze | Arrow keys or WASD |
| Paddle Duel vs computer | W/S or Up/Down |
| Paddle Duel, two players | Left player W/S, right player Up/Down |

## Requirements

- Python 3.10 or newer
- `pygame` 2.6 or newer
- `pygbag` (only to build the web version)

Everything is listed in `requirements.txt`.

---

## Running it in PyCharm

1. Put `arcade_lab.py` and `requirements.txt` in your PyCharm project folder.
2. Open PyCharm's **Terminal** tab at the bottom of the window. It uses your project's Python, unlike Command Prompt.
3. Install the packages:
   ```
   pip install -r requirements.txt
   ```
   (Only need the desktop version? `pip install pygame` is enough.)
4. Right-click `arcade_lab.py` and choose **Run 'arcade_lab'**. The ARCADE LAB menu opens right away.

**High scores:** on the desktop they're saved in `arcade_lab_scores.json`. That file holds Viper Bite's, Brick Fall's and Chomp Maze's best scores plus your Paddle Duel wins and losses. Delete it to reset everything. If the file is missing or damaged, the program starts fresh instead of crashing.

## Publishing on the web (pygbag + Netlify)

1. Make a new folder named `arcade_web`.
2. Copy `arcade_lab.py` into it and **rename the copy to `main.py`** (pygbag needs that name).
3. In PyCharm's Terminal, go to the folder that *contains* `arcade_web`, then test it in your browser:
   ```
   pygbag arcade_web
   ```
   Open `http://localhost:8000`, click the page, and play.
4. Build the website:
   ```
   pygbag --build arcade_web
   ```
   The finished site is in `arcade_web/build/web`.
5. Create a free account at [netlify.com](https://www.netlify.com). Open **app.netlify.com/drop** and drag the `web` folder onto the page. Netlify gives you a link you can share.

**Browser notes**
- You click the page once to start. That click also turns the sound on, because browsers block sound until you interact with the page.
- High scores are saved in the browser's localStorage, so each browser and device keeps its own.
- Esc goes back to the menu but never tries to close the browser tab.
- The page needs an internet connection, because pygbag loads the Python/Pygame runtime online.

## How the program is organized

Everything is in **one Python file**, split into nine sections in this order:

| # | Section | What it contains |
|---|---|---|
| 1 | Shared settings, colors, helpers | Screen size, neon color palette, shared helper functions |
| 2 | Shared components | Sound generator, high-score system, particles and screen shake, base game class |
| 3 | Game 1: Viper Bite | Snake settings (`SN_` prefix) and game class |
| 4 | Game 2: Brick Fall | Tetris settings (`TE_` prefix) and game class |
| 5 | Game 3: Chomp Maze | Pac-Man settings (`PM_` prefix), maze, ghost AI |
| 6 | Game 4: Paddle Duel | Pong settings (`PO_` prefix), computer opponent |
| 7 | Player classes and keyboard controls | Input handling shared by the games |
| 8 | Main menu | 2 x 2 animated game cards with best scores |
| 9 | Application and main loop | Switches between menu and games; `async def main()` |

**Key ideas**
- **Base game class.** Every game is built on the same parent class, which gives it the start screen, pause, game-over screen, personal-best message and return-to-menu behavior. Each game resets completely when you reopen it, and keys pressed in one game never carry into the next.
- **Delta time (`dt`).** Movement uses the time since the last frame, with big jumps capped, so the games run at the same speed on any computer. The loop targets 60 FPS.
- **Sound from math.** Each effect is built as a waveform in code and played with `pygame.mixer.Sound`. If there is no audio device, the games run silently.
- **Web-ready.** The loop uses `async def main()` with `await asyncio.sleep(0)` every frame so the browser never freezes. `sys.platform == "emscripten"` tells the program it is in a browser, and there it saves scores to localStorage through pygbag's browser bridge. The source file is plain ASCII.

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError: No module named 'pygame'` | Pygame went into a different Python. Run `pip install pygame` in **PyCharm's Terminal**, or add it under *Settings > Project > Python Interpreter > +*. |
| `pip install pygame` fails while building | Your Python may be too new for pygame. Try `pip install pygame-ce`; the code works the same with it. Or switch the PyCharm interpreter to Python 3.11 / 3.13. |
| No sound on the desktop | Press **M**, since sound may be toggled off. Check Windows volume. With no audio device, the games run silently by design. |
| No sound in the browser | Click the game page first. Browsers block sound until you interact with the page. |
| High scores disappeared | Desktop: check that `arcade_lab_scores.json` is in the folder you run from. Browser: scores are stored per browser, and clearing site data erases them. |
| Web page stays black or stuck loading | Make sure the file in the folder is named `main.py`. Test with `pygbag arcade_web` first, then press **F12** and read the Console tab. |
| `pygbag` is not recognized | Run `pip install pygbag` in PyCharm's Terminal, or run it as `python -m pygbag arcade_web`. |
| Keys don't respond in the browser | Click inside the game area so the page has keyboard focus. |
